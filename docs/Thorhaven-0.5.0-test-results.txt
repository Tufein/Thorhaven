Thorhaven 0.5.0 Preview — Verification report

Environment: dedicated Android 15 ARM64 emulator with two logical displays
(top 1920×1080, bottom 1240×1080), root Shizuku and a test-only Linux uinput source.

Results:
- 102 existing Android integration/regression checks passed against the signed release APK.
- 43 new feature checks passed using the matching debug build with a debug-only local
  document provider. Production feature code is shared; the provider is excluded from release.
- 10 native helper self-tests passed. The native helper is unchanged from 0.4.
- Forward installation from signed 0.4 to signed 0.5 preserved Unicode notes, language,
  app settings and an existing guide file/metadata.
- Signed release assembly and Android release lint passed.
- Release signature verified; signing certificate matches previous previews.

Scope: new tests cover multiple documents, image import/zoom, normalized map markers,
text search and Unicode offsets, named PDF bookmark bounds, named game profiles,
checklists, panel order, complete ZIP round trips, daily backup-job constraints,
verified automatic archives, seven-archive retention, and failure preservation.
Hardware automation switching/restore/error handling uses a fake asynchronous transport.
Touch-action command validation is tested; physical emulator/game acceptance of these
injected keys is not established by the test.

Limits: no physical AYN Thor was connected. Fan/CPU/RGB responses use fixtures;
physical cooling, firmware compatibility and real game acceptance need on-device checks.
No claim is made about held touch input, analog sticks, ROM detection or panel power-off.
Android controls scheduled-job timing; this run verifies scheduling and backup execution,
not a 24-hour real-time scheduling soak.
